# Carbon Credit Estimation using AI and Algorand Blockchain

## Project Overview
This project estimates carbon credits using satellite imagery and vegetation analysis. 
The system uses NDVI (Normalized Difference Vegetation Index) and machine learning 
techniques to analyze vegetation and calculate carbon absorption.

The estimated carbon credits are stored using Algorand blockchain to ensure 
transparency and security.

## Objectives
- Estimate carbon credits from satellite images
- Analyze vegetation using NDVI
- Apply machine learning models
- Store results on Algorand blockchain

## Technologies Used
- Python
- Machine Learning
- NDVI Vegetation Analysis
- Satellite Image Processing
- Algorand Blockchain
- Google Colab

## Expected Outcome
The system provides accurate carbon credit estimation and secure blockchain storage 
to support environmental sustainability.
